## 关键决策（2026-08-06，Dr Armor 确认）

1. **丰度统一 19% HALEU**（含 KPBS baseline）——航天堆现实丰度（历史 HEU 90%+，现代 NASA/DOE 月球堆 19.75% HALEU），3% 是地面轻水堆丰度无航天先例
2. NFE：质量 ×4、rescaleFactor ×2、热功率 ×4（等比放大，保持功率密度 1,100–1,300 kW/t）
3. 电功率按效率曲线取整 EC/s（kW 可被 3.6 整除）
4. 装载按设计寿命：**tiny ≥30 年，其余 10–15 年**（Dr Armor 2026-08-06 修订）

## 燃料公式（19% HALEU，精确口径）

```
Ratio(u/s) = 热MW × 11.14 g/MWd / 10970 / 86400 = 热MW × 1.175×10⁻⁸
日耗 g/day = Ratio × 86400 × 10.97
```
